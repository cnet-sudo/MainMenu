# Главное меню игры на SFML

![C++](https://img.shields.io/badge/C%2B%2B-14-00599C?logo=cplusplus)
![SFML](https://img.shields.io/badge/SFML-2.6.x-8CC445)

Учебный пример полноэкранного меню для игры на SFML. Проект показывает, как
создать навигацию с клавиатуры, выделение активного пункта, отдельные экраны,
фоновые изображения, музыку и звуки интерфейса.

## Возможности

- пункты «Играть», «Настройки», «Об игре» и «Выход»;
- циклическое перемещение по меню;
- индивидуальные цвета обычного и выбранного текста;
- звуковая обратная связь при навигации;
- отдельная музыка главного и игрового экранов;
- демонстрационные окна игры, настроек и информации;
- вспомогательные классы загрузки ресурсов и покадровой анимации.

## Управление

- **↑ / ↓** — выбрать пункт;
- **Enter** — открыть выбранный раздел;
- **Esc** — вернуться с дочернего экрана.

## Основные файлы

| Файл | Назначение |
|---|---|
| `main.cpp` | состояния меню и демонстрационные экраны |
| `GameMenu.*` | список пунктов, выделение и навигация |
| `AssetManager.*` | загрузка текстур, шрифтов и звуков |
| `Animator.*` | универсальная покадровая анимация |
| `image` | фоны и графические элементы |
| `font` | шрифт меню |
| `audio` | музыка и звуки интерфейса |

## Сборка через CMake

Понадобятся CMake 3.21+, Git и компилятор C++14. SFML 2.6.x загружается при
первой конфигурации.

```powershell
cmake -S . -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build --config Release
./build/Release/GameMenu.exe
```

Ресурсы из `audio`, `font` и `image` копируются рядом с программой.

Для `MainMenu.sln` обновите старые абсолютные пути к SFML 2.5.1 в свойствах
проекта, если ваша библиотека установлена в другом месте.

## Как встроить меню в собственную игру

Вместо создания отдельных окон в функциях `Game`, `Options` и `About_Game`
можно переключать единое состояние приложения. Сам класс `GameMenu` уже
принимает окно и список строк, поэтому его легко переиспользовать.

## Статус

Готовый учебный пример интерфейса. Это не самостоятельная игра: пункт
«Играть» открывает демонстрационный экран.
